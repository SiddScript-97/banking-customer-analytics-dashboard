# Banking Customer Analytics Dashboard

## Overview
This project is an interactive Banking Customer Analytics Dashboard built using Power BI, SQL, and Excel. The dashboard analyzes customer transactions, banking KPIs, revenue trends, and customer behavior to generate meaningful business insights through visualization and reporting.

The project focuses on transforming raw banking datasets into structured analytical reports that support data-driven decision-making.

---

## Objectives
- Analyze banking customer transaction data
- Monitor key financial KPIs
- Identify customer behavior and revenue trends
- Perform data cleaning and reporting
- Build interactive dashboards for business insights

---

## Tech Stack
- Power BI
- SQL
- Microsoft Excel

## Features
- Customer transaction analysis
- Revenue and financial KPI tracking
- Debit and credit trend visualization
- Customer segmentation insights
- Interactive dashboard filters and visuals
- Business reporting and analytics
